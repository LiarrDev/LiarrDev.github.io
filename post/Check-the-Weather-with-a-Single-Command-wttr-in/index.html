用一行命令查天气：wttr.in

我们每天是怎么查看天气的，拿出手机解锁打开天气 App，这个步骤已经养成了肌肉记忆。

当前 AI 时代，如果你恰巧打开了一个终端，那么也许你可以考虑一下用一行命令来查看天气。

wttr.in 对自己的介绍很有趣：

wttr.in — the right way to check curl the weather!

它是一种以控制台为界面的天气预报服务，支持多种信息呈现方式，由开发者 Igor Chubin 创建并开源。它不依赖任何客户端，你只需要 curl 或浏览器就能使用。

这个项目最初只是一个小型项目，旨在作为 wego 的扩展功能来展示面向控制台的服务能力。后来，wttr.in 逐渐发展成为一款受欢迎的天气报告服务，每天处理数以千万计的用户查询请求。

在终端中输入：

➜   curl wttr.in

它就能根据你的 IP 地址查询对应的天气信息，默认显示温度、风速、能见度、降雨量等基本信息，使用 ASCII 字符和 Emoji 渲染在终端里。

实际上它的能力不仅仅于此，比如你可以指定查询地点和语言：

➜   curl 'wttr.in/guangzhou?lang=zh-cn'

甚至你可以写中文：

➜   curl 'wttr.in/广州?lang=zh-cn'

它都能够正确查询。

下面是它支持的地点查询方式：

➜   curl 'wttr.in/paris' # 城市名
➜   curl 'wttr.in/~Eiffel+tower' # 地标名（空格用 `+` 号替代）
➜   curl 'wttr.in/Москва' # 任何语言的 Unicode 城市名
➜   curl 'wttr.in/ctu' # 机场三字代码（成都机场）
➜   curl 'wttr.in/510000' # 邮政编码查询
➜   curl 'wttr.in/-78.46,106.79' # GPS坐标

你可以指定单位：

➜   curl 'wttr.in/beijing?m' # 强制使用公制单位
➜   curl 'wttr.in/newyork?u' # 强制使用美制单位
➜   curl 'wttr.in/london?M' # 风速采用 m/s 显示

还能配置显示选项：

➜   curl 'wttr.in/shenzhen?0' # 只显示当前天气
➜   curl 'wttr.in/shenzhen?1' # 显示当前天气和当天预报
➜   curl 'wttr.in/shenzhen?2' # 显示当前天气和两天预报
➜   curl 'wttr.in/shenzhen?3' # 显示当前天气和三天预报
➜   curl 'wttr.in/shenzhen?F' # 隐藏 Follow 相关内容
➜   curl 'wttr.in/shenzhen?n' # 仅显示昼夜
➜   curl 'wttr.in/shenzhen?q' # 隐藏 Weather report 标题
➜   curl 'wttr.in/shenzhen?Q' # 隐藏 Weather report 标题和城市名
➜   curl 'wttr.in/shenzhen?T' # 去除颜色
➜   curl 'wttr.in/shenzhen?format=3' # 超精简，仅显示天气和温度
➜   curl 'wttr.in/shenzhen?format=j1' # JSON 格式

指定语言：

➜   curl 'wttr.in/foshan?lang=zh-cn' # 参数指定
➜   curl 'zh-cn.wttr.in/foshan' # 域名指定
➜   curl -H "Accept-Language: zh-cn" wttr.in/foshan # 请求头指定

你以为无论怎么查它就是一个简单的天气表格？

温度曲线、降雨柱状图、月相、天文时间等增强信息都能给你安排上：

➜   curl 'wttr.in/hongkong?format=v2'

月相也能给你玩出花：

➜   curl 'wttr.in/moon' # 当前月相
➜   curl 'wttr.in/moon@2026-08-07' # 查询指定日期月相

如果你想把查询的结果生成图片，你不需要截图，用命令保存就行：

➜   curl 'wttr.in/paris.png' --output paris.png # 天气图片
➜   curl 'wttr.in/paris_0pq.png' --output paris_0pq.png # 组合参数
➜   curl 'wttr.in/paris.png?transparency=150' --output paris_t150.png # 透明度，0-255
➜   curl 'wttr.in/paris.png?background=00aaaa' --output paris_bg.png # 背景颜色

更多的功能可以参考项目的文档，在这里就不一一列举了。

如果你不习惯使用终端，在浏览器中直接访问 wttr.in 也可以查看天气信息。

主域名偶尔会因流量过大响应缓慢，官方提供完全等价的备用域名 wttr.is。

需要注意的是，wttr.in 的数据来源于 WorldWeatherOnline，偶尔会出现定位偏差或数据延迟。对于分钟级降水预警这类需求，专业天气 App 仍然是更好的选择。但对于日常快速查看，wttr.in 提供的信息已经足够丰富。

至于为什么要在终端中查看天气？哈哈，我也不知道 😆。

不过我觉得这个工具的应用场景可能会更多的面向开发者，比如在一些工具的状态栏嵌入一行天气信息，或者在脚本或者自动化任务中调用，根据天气条件自动调整服务器散热策略等等。

wttr.in 的优势在于「轻量」和「可编程」。它不会替代专业天气 App 的雷达图和分钟级降水预警，而是在你需要快速看一眼天气时，用最低成本完成这件事。

一行命令，零安装，零广告。这就是 wttr.in 的哲学——最好的工具，是你不需要专门去「打开」的工具。
